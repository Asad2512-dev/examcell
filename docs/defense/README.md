# ExamCell defense package

For a university panel, with technical explanation, speaker notes and a workflow demonstration. Duration target: 15–20 minutes including questions.

- `ExamCell-Defense-Presentation.html`: portable browser presentation with 28 slides, embedded screenshot, architecture diagram and simplified database diagram. No server or internet connection required.
- `ExamCell-Defense-Presentation.pdf`: printable slide copy, when present.
- `Speaker-Notes.md`: narration and source references for every slide.
- `System-Guide-and-Viva.md`: detailed explanation, algorithms, calculations, limitations, demo preparation and viva answers.
- `Schema-and-Code-Inventory.md`: migration/schema operations, models, services, controllers, policies, jobs, test files and registered screens.
- `slide-content.json`: editable slide wording and notes as structured source.

Open the HTML in a browser. Left/Right navigates slides, N toggles speaker notes, F toggles full screen. Print produces all slides. Notes appear on the projected page when enabled, so use the separate notes file for private rehearsal or presenter reference.

Recommended live route: slides 1, 2, 4, 6, 8–18, 20 and 21. Aim for 10–11 minutes of explanation, 3–4 minutes of demonstration and 3–5 minutes of questions. Keep the other slides for reference and panel questions.

Presenter, institution, supervisor and team details were not supplied. Introduce them verbally or edit the HTML title slide before submission. Screenshots contain repository demonstration data. The package explains checked-out source, and does not claim application tests passed, measured performance improvements or production readiness.
